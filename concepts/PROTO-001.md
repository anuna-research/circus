# PROTO-001

`PROTO-001: USDD Agent Protocol` is the binding protocol this vault's
specifications are written against. It fixes the artefact templates, the
traceability obligations, the Orientation block, the Simplicity Ladder, and the
temporal-property notation that [[SPEC-001-circus-agent-harness#ADR-007]]
adopts.

The document is not held in this repository. Its canonical copy travels with
the `anuna-dev` skill, at
`~/.claude/skills/anuna-dev/references/PROTO-001-usdd-agent-protocol.md`.
Version at the time of writing: 1.18.0.

This page exists so that references to the protocol are traversable from the
vault rather than invisible in prose.
